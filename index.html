FAQ

購買前常見問題

付款後怎麼拿到講義？

付款成功後，系統會自動寄一封信到你填的 Email，裡面有 PDF 和指令文字檔的下載連結。10 分鐘內沒收到，請先看垃圾信件匣，再私訊 IG 告訴我們訂單 Email。

我沒有剪輯經驗，也能用嗎？

可以。指令 0 會帶你一步一步裝好環境，每一步都會先說明它在做什麼；需要你按同意或輸入密碼時，Claude 會先停下來告訴你。

一定要付費的 Claude 嗎？

需要 Claude Pro 以上方案，因為要用 Claude Code 在你的電腦上跑程式、輸出影片檔。其他工具、字型和音效都用免費可商用的，不需要另外付 API 費用。

可以退款嗎？

數位內容寄出後就能完整下載，因此購買前會請你勾選同意「寄出後不適用七天解除權」。如果檔案打不開或有缺漏，我們會重新寄送。

可以分享給朋友嗎？

一份購買限一人使用，請不要轉售或公開分享檔案。想團購或企業內訓，歡迎直接私訊洽詢。
