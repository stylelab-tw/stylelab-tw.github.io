# 風格研究所 Style Lab 官網

網站：https://stylelab-tw.github.io

- `index.html` 首頁（數位商品・服務・關於）
- `services.html` 短影音服務報價與試算
- `workshop.html` 短影音剪輯實戰工作坊
- `coaching.html` 14 天短影音陪跑班（內嵌 Apps Script 匯款報名表 `?join=1`）
- `works.html` 作品集（分類篩選、作品卡片；加 `data-embed` 可在頁內播放 IG／YouTube）
- `assets/` 樣式、字型（已子集化）、圖片

原始檔與產生腳本在專案資料夾「風格研究所官網/src」（build_multi.py）。

字型：標題與內文用源泉圓體（GenSen Rounded，SIL OFL 1.1，見 assets/FONT-LICENSE-OFL.txt）；英文 Jost、Cormorant Garamond（OFL）。
